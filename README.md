# เกมส์โดรามอน 🔔

เกมไพ่วงเหล้าสุดฮา เล่นพร้อมกันได้ทั้งวง — แต่ละคนใช้มือถือของตัวเอง
หัวตี้สร้างวง แชร์ลิงก์ให้เพื่อน แล้วเปิดไพ่ไปเรื่อยๆ ใครได้ไพ่อะไรก็ทำตามนั้น

> ดื่มอย่างรับผิดชอบนะครับ 🍻 เกมนี้ทำมาเพื่อความสนุกในวงเพื่อนที่บรรลุนิติภาวะแล้ว
> ทุกกฎเปลี่ยนเป็น "ดื่มน้ำเปล่า" หรือ "ทำท่าตลก" แทนก็เล่นสนุกเหมือนกัน

## เล่นยังไง

1. **หัวตี้** เข้าหน้าแรก ใส่ชื่อ กำหนดจำนวนสมาชิกในวง (2–12 คน) แล้วกด **สร้างวงใหม่**
2. ได้ **รหัสวง 4 ตัว** กับ **ลิงก์เชิญ** — กดแชร์เข้า LINE/กลุ่มได้เลย
3. **เพื่อน** เปิดลิงก์ ใส่ชื่อตัวเอง แล้วเข้าวง (หรือกรอกรหัส 4 ตัวที่หน้าแรก)
4. หัวตี้กด **เริ่มเกม** — ระบบ **สุ่มคนเริ่ม** ให้เอง
5. พอถึงตาใคร มือถือเครื่องนั้นจะ **สั่น + มีเสียงกระดิ่งเตือน** แตะที่ไพ่เพื่อเปิด
6. ทุกเครื่องเห็นไพ่ที่เปิดพร้อมกัน อ่านกฎบนไพ่ ทำตาม แล้วกด **จบตา** ส่งต่อคนถัดไป
7. ไพ่หมดสำรับ (52 ใบ) = จบรอบ หัวตี้กดเริ่มรอบใหม่ได้

## กฎไพ่

| ไพ่       | กฎ                                                                                |
| --------- | --------------------------------------------------------------------------------- |
| **A–4**   | ดื่ม 1–4 อึกตามหน้าไพ่                                                            |
| **5**     | จับบัดดี้ 1 คน — จากนี้ถ้าใครในคู่โดนดื่ม อีกคนต้องดื่มด้วย                       |
| **6**     | เกมหมวดหมู่ — ตั้งหัวข้อแล้วไล่กันไป ใครตอบไม่ได้/ช้า ดื่ม 1 อึก                  |
| **7**     | เกมเลข 7 — ข้ามเลขที่ลงท้ายด้วย 7 หรือหารด้วย 7 ลงตัว ผิดดื่ม 1 อึก               |
| **8**     | ไพ่ติดตัว — เก็บไว้ใช้เอง (หรือให้เพื่อน) เพื่อไปห้องน้ำ                          |
| **9**     | คนทางซ้ายของคนเปิด ดื่ม 1 อึก                                                     |
| **10**    | คนทางขวาของคนเปิด ดื่ม 1 อึก                                                      |
| **J**     | เกมจับคาง — คนสุดท้ายที่ทำตาม ดื่ม 1 อึก                                          |
| **Q**     | ห้ามพูดกับคนที่ได้ไพ่นี้ ถ้าพูดด้วยโดน 1 อึก                                      |
| **K**     | ใบ 1 กำหนด "ทำอะไร" ใบ 2 "ที่ไหน" ใบ 3 "ยังไง/นานเท่าไหร่" **ใบ 4 โดนเอง** 💀     |
| **ตลอดเกม** | **ห้ามชี้นิ้ว** (เพราะเราเป็นโดเรมอน) ถ้าชี้ก็โดน 1 อึก                        |

เกมช่วยจำสถานะให้ทั้งหมด: คู่บัดดี้ ไพ่ 8 ที่ใครถืออยู่ ใครโดน Q และ K เปิดไปกี่ใบแล้ว
ไพ่ 9/10 จะบอกชื่อคนที่ต้องดื่มให้ตรงๆ ไม่ต้องนับซ้ายนับขวาเอง

## รันโปรเจกต์

```bash
pnpm install
pnpm dev          # http://localhost:3000
```

เทสกับมือถือจริงในวง LAN เดียวกัน: `pnpm dev` จะพิมพ์ URL แบบ `http://192.168.x.x:3000` ให้ใช้ได้เลย

```bash
pnpm build        # production build
pnpm start        # รัน production
pnpm typecheck    # ตรวจ TypeScript
```

## เทคโนโลยี

- **Next.js 16** (App Router) + **React 19** + **TypeScript**
- **Tailwind CSS 4** — ธีมและ animation ทั้งหมดอยู่ใน `src/app/globals.css`
- **Server-Sent Events** สำหรับ realtime — ทุกเครื่องเห็น state ตรงกันทันที ไม่ต้องรีเฟรช
- **Web Audio API** สร้างเสียงเตือนจากโค้ดตรงๆ (ไม่มีไฟล์เสียงให้โหลด) + `navigator.vibrate`
- ไม่มี database — สถานะวงเก็บใน memory ของเซิร์ฟเวอร์

## ข้อควรรู้ก่อน deploy

สถานะวงเก็บอยู่ **ใน memory ของ process** (`src/lib/server/rooms.ts`) ซึ่งดีพอสำหรับ
`pnpm dev`, VPS, Docker หรือ container เดียว แต่ **ใช้กับ serverless หรือหลาย instance ไม่ได้**
เพราะแต่ละ instance จะเห็นห้องไม่ตรงกัน และ SSE ก็ผูกกับ process ที่ถือห้องนั้นอยู่

ถ้าจะขึ้น Vercel หรือสเกลหลาย instance ให้เปลี่ยน `Map` ใน `rooms.ts` ไปเป็น Redis
(เก็บ state + ใช้ pub/sub แทน `listeners`) ส่วนที่เหลือของโค้ดไม่ต้องแก้ — ทุก route
คุยกับไฟล์นี้ผ่านฟังก์ชันที่ export ไว้แล้ว

ห้องที่ไม่มีใครแตะเกิน 6 ชั่วโมงจะถูกลบทิ้งอัตโนมัติ

## หมายเหตุ

โลโก้และกราฟิกในเกมวาดขึ้นใหม่ทั้งหมด (กระดิ่ง + ลายหนวด) ไม่ได้ใช้ตัวละครหรือ
งานลิขสิทธิ์ของใคร ชื่อ "เกมส์โดรามอน" ใช้ตามที่วงเหล้าไทยเรียกกันติดปาก
